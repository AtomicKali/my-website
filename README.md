# Quantum Verse 2026

Static event landing page for T.J.S Polytechnic College — Department of Computer Science & Engineering.

## Deploy on Render

1. Push this repo to GitHub.
2. On [render.com](https://render.com): **New +** → **Blueprint** → connect this repo.
   Render will detect `render.yaml` and configure everything automatically.
   (Alternatively: **New +** → **Static Site**, Build Command blank, Publish Directory `.`)
3. Click **Apply** / **Create Static Site**. Your site will be live at a `*.onrender.com` URL within a minute or two.
